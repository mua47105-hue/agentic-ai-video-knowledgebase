# essentia

## What it is
essentia is an open-source (AGPLv3) C++ library with Python bindings for
audio analysis and music information retrieval (MIR). Developed by MTG/UPF.

## License: AGPLv3 — DISQUALIFIED

**essentia is NOT integrated into this repo.** Its AGPLv3 license is viral
copyleft — using it would require the entire repo to be relicensed under AGPLv3.
