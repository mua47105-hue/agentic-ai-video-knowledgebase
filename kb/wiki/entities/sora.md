# Sora

OpenAI's video generation model. **Sora is being discontinued.** The web and app experiences shut down on April 26, 2026. The API will shut down on September 24, 2026.

**Do not start new work on Sora.**

## Historical significance

Sora was the first model to demonstrate photorealistic text-to-video with physical world simulation. In its prime, it was the quality leader, but access was always limited and costs were extreme (~$1M/day compute vs $2.1M lifetime revenue). The user base fell from 1M to <500K. A reported $1B Disney deal collapsed.

## Migration advice

Export your content at sora.chatgpt.com/sunset before September 24, 2026. Primary migration targets: [Google Veo 3](../entities/google-veo-3) (narrative/audio) and [Runway Gen-4](../entities/runway-gen-4) (control/production).
