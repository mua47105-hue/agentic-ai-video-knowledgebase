# Shorz

Desktop AI video editor that edits for you — describe the edit and it handles the heavy lifting. Uniquely **agent-callable via MCP**: Cursor, Claude Code, Codex, and Gemini can drive it directly.

## Architecture

Windows desktop app with a multi-model backend routing tasks across: OpenAI GPT-5, Claude Opus, Google Veo 3.1, Nano Banana 2, ElevenLabs, Kling 3.1, ByteDance Seedance. Exposes an MCP interface for AI agent orchestration.

## Capabilities

- Auto-edit: raw clips → finished edit from description
- Text-to-video, AI avatar, podcast-to-video
- Auto-clipping (long video → viral shorts)
- Auto B-roll, titles, subtitles, auto-zoom, face tracking
- Transitions, motion, music, sound
- Thumbnail creator, animation studio
- Direct upload to YouTube/TikTok
- **Agent-callable**: Cursor/Claude/Codex/Gemini can set up projects, generate assets, kick off workflows

- No free trial (AI has real costs)
- Credits don't roll over between packs

Only AI video editor with MCP-native agent-callability — lets coding agents drive it directly. Credit-based (no subscription) with permanent commercial rights.
