# Kling 3.0

Kuaishou's cinematic AI video generation model. The strongest value option for native 4K output with multi-language audio support. Over 60M creators and 600M+ videos generated.

## Capabilities

- **Native 4K** output — only major model with native (non-upscaled) 4K
- **Omni Native Audio** — multi-language, dialects, accents, multi-character dialogue
- **Video 3.0 Omni** — unified multimodal (text/image/audio/video in one model)
- **Multi-shot storytelling** with intelligent camera direction
- **Element consistency** via reference video/images
- **Video O1 model** for reasoning-based generation
- **Up to 15s** per clip (longest native of any major model)

## Specifications

| Spec | Value |
|------|-------|
| Max resolution | Native 4K |
| Max clip length | 15s per clip |
| Native audio | Yes — Omni Native Audio |
